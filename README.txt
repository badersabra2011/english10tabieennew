English 10 - Tabieen School App
الملفات (ارفعها كلها في جذر المستودع Root):
1- index.html = الصفحة الرئيسية
2- style.css = التصميم والألوان
3- app.js = المحتوى والوحدات والأسئلة والمنطق
4- manifest.json = يجعل الموقع تطبيق قابل للتثبيت على الشاشة
5- sw.js = يجعله يعمل بدون إنترنت
+ icon.png = أيقونة التطبيق (يمكنك استبدالها بشعار المدرسة)

مهم: اسم الملف الأول يجب أن يكون index.html بحرف i صغير.
بعد الرفع: Vercel > Deployments > Redeploy
